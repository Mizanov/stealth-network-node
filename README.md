# 🚀 Multi-Transport Stealth Network Node

### 🛡️ Xray REALITY Vision & XHTTP | Sing-Box Hysteria 2 Salamander & WS TLS | Dedicated Telegram Bot

Готовое решение «под ключ» для развёртывания на чистом VPS: легковесный (<120 МБ RAM, без Docker), мультитранспортный защищённый сетевой узел на базе **Xray-Core** (высокоскоростной транспорт **VLESS + REALITY + Vision**, защищённый потоковый транспорт **VLESS + XHTTP + REALITY** с защитой **Self-SNI**), **Sing-Box** (скоростной протокол **Hysteria 2** с обфускацией **Salamander** на порту **443 UDP**, legacy VLESS / Trojan WS + TLS), сайт-маскировка студии дизайна (HTTP 200 OK) и персональный **Telegram-бот** для автоматической генерации профилей и универсальных подписок для **Incy, Happ, Sing-Box, Shadowrocket, v2rayN / v2rayNG, Streisand, Surge, Hiddify, Nekobox** и других современных клиентов.

## 🌟 Ключевые возможности

* **Мультитранспортная архитектура нового поколения (Xray-Core + Sing-Box)**:
  * ⚡ **Основной транспорт — VLESS + REALITY + Vision (TCP) на порту 8443**: 0-RTT, минимальные накладные расходы, сверхвысокая скорость и минимальный расход батареи на мобильных устройствах.
  * 🛡️ **Резервный транспорт — VLESS + XHTTP + REALITY на порту 8444**: новейший потоковый транспорт Xray, эмулирующий стандартные HTTP-запросы для устойчивости в нестабильных сетях с глубокой инспекцией пакетов.
  * 🚀 **Скоростной Hysteria 2 (Hy2) с обфускацией Salamander на порту 443 (UDP)**: модифицированный протокол QUIC со встроенным контролем перегрузок Brutal CC и обфускацией заголовков `salamander`. Работает на стандартном порту 443/UDP (HTTP/3), обеспечивая стабильную пропускную способность на радиоканалах с высоким процентом потери пакетов.
  * 🔒 **Self-SNI защита (Защита от несоответствия сертификата)**: SNI указывает строго на **собственный домен сервера**, а fallback REALITY направляется на локальный веб-сервер Nginx (`127.0.0.1:443`). При внешних проверках IP-адрес соединения на 100% совпадает с DNS A-записью домена.
  * 🌐 **100% обратная совместимость (WS + TLS на порту 443 TCP)**: Sing-Box продолжает обслуживать VLESS WS и Trojan WS через Nginx для классических клиентов.
* **Универсальные профили и подписки для всех клиентов ([Incy](https://incy.app), [Happ](https://github.com), [Sing-Box](https://sing-box.sagernet.org), Shadowrocket, Surge, v2rayN/v2rayNG, Streisand)**:
  * Единая **Base64-подписка** (`.txt`), содержащая сразу **5 сетевых профилей**:
    1. `⚡ [XTLS-Reality-Vision] VLESS` (8443/tcp, Self-SNI)
    2. `🛡️ [XHTTP] VLESS` (8444/tcp, REALITY XHTTP, Self-SNI)
    3. `🚀 [Hy2] Hysteria 2 - Salamander` (443/udp, QUIC, TLS 1.3)
    4. `🌐 [WS] VLESS (over TLS)` (443/tcp, ws)
    5. `🔒 [WS] Trojan (over TLS)` (443/tcp, ws)
  * Чистые `.json` профили для оригинального ядра Sing-Box с селектором outbounds и встроенными правилами маршрутизации (GeoIP, GeoSite).
  * Готовый клиентский конфиг `*-hy2.json` для Sing-Box, Shadowrocket, Nekobox и других клиентов с поддержкой Hysteria 2.
* **Умный Telegram-бот управления**:
  * 🎨 **Космический стиль и брендинг**: оригинальный аватар с парящим космонавтом, подробное и весёлое приветствие, вызывающее улыбку и снимающее любые вопросы при первом запуске.
  * 🚀 **Мгновенный Self-Service (выпуск в один клик)**: единоразовая персональная выдача универсальной подписки (5-в-1) с защитой от повторного выпуска (один ключ в одни руки).
  * Быстрая выдача профилей администратором командой `/new <имя>` или кнопкой меню.
  * Управление списком пользователей (`/list`, `/del`).
  * 📊 **Учёт сетевого трафика каждого пользователя (`/stats`)**: статистика скачивания (download) и отдачи (upload) в реальном времени, постоянное сохранение истории при перезагрузках VPS, быстрое обнуление трафика (`/rst`).
  * Мониторинг состояния сервера (`/status` — Sing-Box, Xray-Core, Nginx, CPU, RAM, диск и суммарный сетевой трафик).
* **Защита от активного сетевого сканирования (Anti-Probing & Self-SNI Stealth)**:
  * **Премиальный White-Site студии дизайна (`ORBITA // DESIGN LAB`)**: корень домена отдаёт полнофункциональный, высокоэстетичный веб-сайт космической цифровой студии дизайна с кодом **200 OK** (интерактивный Canvas-звездопад 60 FPS, 3D-параллакс космонавта, карточки кейсов *Landfall*, *Sova+rest*, *Relay*, *Metricra*, манифест Anti-Slop, интерактивная форма передачи брифа, `robots.txt` и `sitemap.xml`).
  * **Архитектурный стандарт [Hallmark Anti-Slop](https://github.com/Nutlope/hallmark) и [AI Design Skills](https://github.com/elayadesign/ai-design-skills)**: ультралёгкая чистая архитектура без тяжелых JS-фреймворков (~40 КБ, отклик < 20 мс, 100/100 в Google Lighthouse), кинетическая типографика (*Space Grotesk* + *Plus Jakarta Sans* + *JetBrains Mono*) и матовые стеклянные поверхности.
  * **Self-SNI (Принцип честного домена)**: в отличие от заимствования сторонних доменных имен, которые вызывают сетевые коллизии из-за несовпадения ASN и IP-адресов при анализе сетевого маршрута, в нашем решении SNI указывает строго на **ваш собственный домен**. При любых внешних диагностических запросах или проверке сертификата сервер возвращает валидный Let's Encrypt TLS-сертификат и открывает сайт студии дизайна. Полная сетевая прозрачность и консистентность.
  * **Никаких дефолтных редиректов**: сетевые сканеры по IP не видят сторонних редиректов или ошибок 403/404 — сырой IP-трафик сбрасывается без ответа (HTTP 444), а доменный трафик выглядит как легитимная студия дизайна.
  * **Полная изоляция секретных путей**: пути транспортов VLESS/Trojan и веб-подписки доступны только по строго секретным длинным хэш-ссылкам.
* **Сверхэффективное использование ресурсов**:
  * Исключение Docker позволило снизить фоновое потребление оперативной памяти до **<120 МБ**, что делает сервер стабильным на базовых VPS с 1 CPU и 1 GB RAM.
* **Комплексная безопасность Zero-Trust**:
  * Изолированный системный пользователь `incy-bot` без shell-доступа.
  * Автоматический фаервол UFW с закрытием всех внутренних портов.
  * Защита SSH: полное отключение входа по паролю (`PasswordAuthentication no`, доступ строго по криптографическим ключам) и бан на 24 часа через Fail2ban.
  * Тюнинг сетевого стека Linux (BBR, SYN Cookies, защита от IP-спуфинга).
  * Автоматический ежедневный бэкап настроек и сертификатов в `/var/backups/vps/`.

## 📋 Требования к серверу

* **ОС**: Ubuntu 22.04 LTS / Ubuntu 24.04 LTS или Debian 12 (чистая установка).
* **Характеристики**: 1 vCPU, 1 GB RAM (достаточно даже самого доступного VPS с 1 GB RAM), 10 GB диска.
* **Порты**: Открытые порты 22, 80, 443 (TCP и UDP), 8443, 8444 (TCP).
* **Домен**: Собственный домен (например, `node.yourdomain.com` или бесплатный от DuckDNS `yourname.duckdns.org`), направленный на IPv4 сервера.

## ⚡ Быстрая установка

Подключитесь к вашему VPS по SSH с правами `root`:

```bash
git clone https://github.com/Mizanov/stealth-network-node.git /opt/stealth-network-node
cd /opt/stealth-network-node
chmod +x install.sh
./install.sh
```

В процессе установки скрипт запросит:
1. **Main Domain**: Ваш основной домен (A-запись, направленная на IP вашего сервера).
2. **Email**: Email для выпуска бесплатных SSL-сертификатов Let's Encrypt.
3. **Telegram Bot Token**: Токен, полученный от бота [@BotFather](https://t.me/BotFather).
4. **Telegram Admin ID**: Ваш числовой Telegram ID (можно узнать через бота [@userinfobot](https://t.me/userinfobot)).

Скрипт автоматически настроит и запустит все компоненты за 2–3 минуты.

## 📱 Управление через Telegram-бота (Двухуровневая архитектура)

Бот поддерживает разделение на **Личный кабинет участника** (для участников сообщества, сотрудников или доверенных лиц) и **Панель администратора**.

### 1. Личный кабинет участника (Self-Service Access Portal)
* **Авторизация по ссылке**: Участник переходит по ссылке бота (`/start`) со своего Telegram-аккаунта.
* **Единоразовый выпуск профиля («🚀 Запросить доступ»)**:
  * Бот автоматически регистрирует профиль, привязывает его к Telegram ID, имени и юзернейму (`@username`).
  * Присылает **QR-код** (с закодированной подпиской 5-в-1), кнопку **«🚀 Подключить подписку (5-в-1)»** и прямые конфигурационные строки.
  * **Защита от повторного выпуска (Single-issue lock)**: после выпуска кнопка блокируется, участник не может создавать дубликаты ключей.
* **Кабинет («📱 Мой профиль», «📊 Мой трафик»)**:
  * Участник в любой момент может посмотреть свой QR-код, получить универсальную подписку и прямые ссылки, проверить объём переданного трафика и открыть встроенную инструкцию по настройке приложений.

### 2. Панель администратора
Доступна только авторизованным Telegram ID (`TELEGRAM_ADMIN_IDS`):
* **`➕ Создать ключ`** или команда `/new <имя>`:
  * Ручная генерация профиля для нового устройства или участника.
* **`👥 Список участников`** или команда `/list`:
  * Компактный список всех учётных записей с отображением привязки к Telegram (`@username`, имя, ID), кнопками перехода в карточку участника (`🔗 <имя>`) и быстрого отзыва доступа (`🗑 Удалить`). В карточке участника отображаются трафик и три копируемые ссылки: на универсальную подписку, конфиг Sing-Box и конфиг Hysteria 2 (JSON), а также управление токеном и сброс трафика.
* **`📊 Трафик пользователей`** или команда `/stats`:
  * Сводная статистика сетевого трафика по всему серверу и детализация по каждому пользователю с сортировкой по потреблению. В карточке пользователя доступен сброс счётчика трафика (`/rst`) и ротация токена подписки.
* **`📊 Статус сервера`** или команда `/status`:
  * Мониторинг служб Sing-Box, Xray-Core, Nginx, суммарного сетевого трафика узла, свободной оперативной памяти и диска.

### 3. Подключение в клиентских приложениях

Сгенерированные ботом профили и подписки поддерживаются всеми популярными клиентами:

* **Incy / Happ (iOS, Android)**:
  * **Вариант А (самый быстрый):** Нажмите **«+» ➔ «Сканировать QR-код»** и наведите камеру на QR-код из сообщения бота или нажмите кнопку **«🚀 Подключить подписку (5-в-1)»**. Узлы добавятся мгновенно.
  * **Вариант Б (подписка с автообновлением):** Скопируйте ссылку на подписку (`.txt`) из бота, откройте приложение ➔ «Подписки» ➔ «Добавить» ➔ Вставьте ссылку. Узлы загрузятся и будут автоматически обновляться при изменениях на сервере.
* **Sing-Box / SFM / SFI (macOS, iOS, Windows, Android)**:
  * Импортируйте ссылку на подписку (`.txt`) через пункт «Profiles» / «Add Remote Profile» либо загрузите готовый `.json` файл.
* **v2rayN (Windows) / v2rayNG (Android)**:
  * Скопируйте `vless://` строку из сообщения бота ➔ нажмите «Импорт из буфера обмена» (Ctrl+V в v2rayN или значок «+» в v2rayNG), либо добавьте ссылку подписки.
* **Streisand / FoXray / Karing (iOS, macOS, Android)**:
  * Нажмите «+» ➔ добавьте ссылку подписки (тип: Base64 / V2Ray) или отсканируйте QR-код.
* **Shadowrocket / Surge (iOS, macOS)**:
  * Нажмите «+» ➔ добавьте ссылку подписки (`.txt`) либо прямую URI-ссылку `hysteria2://` из сообщения выдачи профиля для прямого подключения по протоколу **Hysteria 2** (443/UDP с обфускацией Salamander).
* **Nekobox / v2rayN / Sing-Box (Десктопные клиенты)**:
  * Скопируйте ссылку **«🚀 Конфиг Hysteria 2 (JSON)»** из карточки пользователя в боте и импортируйте готовый JSON-конфиг для скоростного туннелирования.

## 🛠 Обслуживание и команды

```bash
# Проверка статуса всех компонентов
systemctl status xray sing-box nginx incy-bot

# Просмотр логов Telegram-бота
journalctl -u incy-bot.service -f

# Просмотр логов ядра Xray
journalctl -u xray -f

# Просмотр логов ядра Sing-Box
journalctl -u sing-box -f

# Проверка активных блокировок в Fail2ban
fail2ban-client status sshd

# Просмотр правил фаервола UFW
ufw status verbose

# Проверка параметров безопасности ядра Linux
sysctl net.ipv4.tcp_congestion_control net.ipv4.tcp_syncookies net.ipv4.conf.all.rp_filter

# Быстрый аудит и наложение всех слоёв безопасности
bash scripts/setup-security.sh

# Создание резервной копии конфигураций и сертификатов
backup-vps

# Тест автопродления SSL-сертификатов (Zero-Downtime Webroot)
certbot renew --dry-run

# Перезапуск сервисов при необходимости
systemctl restart xray sing-box nginx incy-bot fail2ban
```
